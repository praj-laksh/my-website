# Prajwal Lakshminath — Quantitative Finance Portfolio

A responsive portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Approved colour palette
- Navy: `#2F4156` — headings and body text
- Teal: `#567C8D` — links, buttons and accents
- Sky Blue: `#C8D9E6` — prominent light section backgrounds
- Beige: `#F5EFEB` — subtle light surfaces
- White: `#FFFFFF` — primary background and cards

White and Sky Blue are the dominant backgrounds. Navy and Teal are used for readable dark text and accents. Manrope is the only font across the entire site. The portfolio uses a fixed light theme.

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js` and the `assets` folder together.
3. Open `index.html` in a browser.

Optional local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Before publishing
- Replace `assets/resume.pdf` with the latest résumé if needed.
- Replace `assets/profile-placeholder.svg` with a professional headshot if desired.
- Add verified LinkedIn and GitHub URLs when available.
- The contact form opens the visitor's email application; it does not submit to a server.
- The charts are illustrative, not live market data or investment performance.

## Deploy
Upload the complete extracted folder to GitHub Pages or Netlify. No build step is required.
